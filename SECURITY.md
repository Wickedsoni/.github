# Security policy

Please **don't open a public issue** for security problems.

Report them privately through the repository's **Security → Report a vulnerability** tab, or email
**wickedsoni27@gmail.com** with "SECURITY" in the subject. Include steps to reproduce and the version affected.

You'll get a reply within 3 working days. Fixes ship as a patch release, and you'll be credited unless you'd rather not be.
